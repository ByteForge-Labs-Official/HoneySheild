# Compliance Notes

* **GDPR** — attacker-derived IPs may be personal data. We retain them only as
  long as needed for threat research (default 90 days), and never share raw data
  outside the operator team.
* **CFAA / equivalents** — never place honeypots on networks you don't own.
  Use a dedicated VPS with the provider's ToS permitting research honeypots.
* **Export controls** — captured exploit payloads are stored only for the
  purpose of defensive research; sharing is restricted to vetted partners.
